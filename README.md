# 🤖 Android Project

A webpage about the history of the Android operating system built with HTML and CSS.

This project was developed during the **HTML5 and CSS3 course** taught by Professor Gustavo Guanabara from Curso em Vídeo.

🔗 Live Demo  
https://devdiegorosa.github.io/projeto-android/

---

## 👨‍💻 About the Project

This project presents information about the history and development of the Android operating system.

The goal of this project was to practice HTML structure, CSS styling and responsive layouts while creating an informative and visually organized webpage.

---

## 🚀 Features

- Responsive layout
- Structured article content
- Images and illustrations
- Embedded video section
- Clean and readable layout

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Responsive Design

---

## 🎯 What I Learned

While building this project I practiced:

- Structuring webpages with semantic HTML
- Creating layouts with CSS
- Styling text and images
- Organizing long-form content
- Improving UI readability
